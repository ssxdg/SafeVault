# SafeVault 密码保险箱

适用版本：v5.0.0 · Windows 10/11

SafeVault 是本地密码管理工具，支持账号密码、网址与 Token、分类标签和多标签记事本。密码库保存在本机并加密，使用前需设置主密码。

## 安装与首次使用

1. 运行安装包或便携版程序。
2. 首次启动时设置并确认主密码；已有密码库则输入主密码解锁。
3. 通过左侧“+ 添加标签”建立分类，再在目标标签下添加账号或网址。

主密码不会保存；忘记后无法恢复密码库。详细安装与操作步骤见 [SafeVault 操作手册](docs/SafeVault-User-Manual.md)。

## 标签、账号与网址

- 点击左侧“+ 添加标签”创建分类；双击标签名称可改名，拖拽可排序。
- 选中标签后，点击“+ 账号密码”或“+ 网址”填写并保存。账号可设置网站或 Windows 程序填充目标。
- 点击卡片或列表中的编辑、删除按钮管理记录；密码与 Token 可显示、隐藏或复制。
- 在顶部搜索框搜索当前分类的账号或网址，并切换卡片或列表视图。
- 删除标签会同时删除其中的账号和网址，请先确认内容是否仍需保留。

## 记事本

点击左侧“记事本”进入。通过顶部“+”新建记事本标签，双击标签名称改名；输入内容后自动保存。记事本与账号分类互不影响。

## 浏览器扩展

1. 在 Chrome 或 Edge 的扩展管理页开启开发者模式，加载 `browser-extension` 目录。
2. 复制扩展 ID，在 SafeVault 底部“扩展设置”中登记，并按提示完成配置。
3. 保持密码库解锁，打开登录页面，点击扩展图标，选择账号填充。提交前请核对，扩展不会自动提交表单。
4. 手动添加账号时，填写账户名称、用户名和密码，选择要保存的标签，再点击“保存账号”。在扩展弹窗中双击已有标签名称可改名；默认标签不能改名。

登录后扩展也可能提示保存新账号；确认后会保存到默认标签。网页更改密码时，可按提示确认更新已有账号。

## Windows 程序填充

编辑账号时配置 Windows 程序登录目标。在目标程序的标准登录输入框中，通过 SafeVault 的填充操作选择账号。具体配置与支持范围见 [操作手册](docs/SafeVault-User-Manual.md)。

## 备份、恢复与锁定

- 使用底部“导出”创建加密备份，使用“导入”恢复或合并数据。
- 标题栏可手动锁定密码库，也可设置无操作自动锁定时间。
- 关闭主窗口后程序可留在系统托盘；需要彻底退出时使用托盘菜单的“退出”。
