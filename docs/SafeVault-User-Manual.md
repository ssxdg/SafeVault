# SafeVault 操作手册

适用版本：v4.0.0<br>
适用系统：Windows 10/11  
更新日期：2026-09-21

## 1. 产品简介

SafeVault 是一款本地离线密码管理工具，可管理账号密码、网址 Token 和多标签记事本，并提供 Chrome、Edge 网站填充及部分 Windows 程序填充能力。

- 密码库以加密 JSON 文件保存在本机，不上传服务器。
- 主密码不会保存，忘记后无法找回。
- 网站和程序必须先配置明确的登录目标，SafeVault 才会提供对应凭据。
- 所有填充均由用户主动触发，不会自动提交登录表单。

> 建议首次使用后立即创建一份加密备份，并将主密码保存在可信的离线位置。

## 2. 安装与启动

### 2.1 安装版

1. 运行 `密码保险箱 Setup 4.0.0.exe`。
2. 按安装向导选择安装目录。
3. 安装完成后，从桌面或开始菜单启动“密码保险箱”。

### 2.2 便携版

1. 将 `密码保险箱 4.0.0.exe` 放在可信目录。
2. 双击启动。
3. 密码库仍保存在当前 Windows 用户的数据目录，不会保存在便携版程序旁边。

### 2.3 数据位置

默认加密密码库位于：

```text
C:\Users\<用户名>\AppData\Roaming\safe-vault\safe_vault.json
```

请勿在程序运行时手工编辑该文件。卸载程序默认不会删除密码库。

## 3. 首次创建或迁移密码库

### 3.1 新用户创建密码库

首次启动且本机不存在密码库时：

1. 界面显示“创建本地加密密码库”。
2. 输入不少于 12 个字符的主密码。
3. 再次输入相同主密码。
4. 点击“创建并进入”。

主密码应同时包含足够长度和随机性，不建议使用姓名、手机号、生日或其他网站正在使用的密码。

### 3.2 迁移旧版明文数据

检测到旧版明文 `safe_vault.json` 时：

1. 界面显示“加密现有密码库”。
2. 设置并确认不少于 12 个字符的主密码。
3. 点击“加密并进入”。
4. 等待程序完成备份、加密和回读验证。

迁移失败时不要删除原文件或备份，应先根据界面错误检查文件权限和磁盘空间。

### 3.3 日常解锁

1. 启动 SafeVault。
2. 输入创建密码库时使用的主密码。
3. 点击“解锁”。

连续输入错误密码会触发短暂等待。主密码无法通过扩展、备份文件或开发人员恢复。

## 4. 界面与基础操作

### 4.1 标签分类

- 点击左侧“+ 添加标签”创建分类。
- 双击标签名称进行重命名。
- 拖拽标签可调整顺序。
- 删除标签会同时删除其中的账号和网址，操作无法撤销。

### 4.2 锁定和自动锁定

标题栏可以选择无操作自动锁定时间：

- 5 分钟
- 15 分钟
- 30 分钟
- 60 分钟
- 自定义 1–1440 分钟
- 不自动锁定

选择“自定义时间”后，在分钟输入框填写整数并按回车或移出焦点。选择“不自动锁定”只关闭空闲计时器；点击标题栏锁定按钮、Windows 锁屏或应用退出仍会锁定密码库。该设置会保存在本机并在下次启动时继续生效。

### 4.3 窗口操作

- “置顶”可让窗口保持在其他普通窗口上方。
- 关闭按钮默认将程序隐藏到系统托盘，不会直接退出。
- 双击托盘图标可恢复窗口。
- 需要完全退出时，在托盘菜单中选择“退出”。

## 5. 管理账号密码

### 5.1 添加账号

1. 选择左侧目标标签。
2. 点击右上角“+ 账号密码”。
3. 填写账户名称、账号、密码、邮箱和备注等信息。
4. 根据需要配置“自动填充目标”。
5. 点击“保存”。

未配置自动填充目标时，该账号仍可正常查看和复制，但不会提供给浏览器或桌面自动填充。

### 5.2 编辑和删除

- 点击账号卡片或列表中的编辑按钮修改内容。
- 点击删除按钮并确认后永久删除该账号。
- 删除前如有保留需要，先执行加密导出。

### 5.3 查看和复制

- 点击密码旁的显示按钮切换显示或隐藏。
- 点击复制按钮复制账号、密码或邮箱。
- 敏感内容通过 SafeVault 复制时，默认在 30 秒后清理；如果用户随后复制了其他内容，SafeVault 不会删除用户的新剪贴板内容。

## 6. 管理网址和 Token

1. 选择目标标签。
2. 点击“+ 网址”。
3. 填写网站名称、完整网址、Token/Key 和备注。
4. 点击“保存”。

网址仅允许通过系统浏览器打开 `http` 或 `https` 地址。Token 默认隐藏，可按需显示或复制。

## 7. 使用记事本

1. 点击左侧“记事本”。
2. 点击记事本标签栏中的“+”创建记事本。
3. 双击标签名称进行重命名。
4. 直接输入内容，停止输入后会自动保存。
5. 按 `Tab` 可插入两个空格。

删除记事本需要确认，系统始终保留至少一个记事本。

## 8. 配置网站自动填充规则

网站规则配置在账号编辑窗口的“自动填充目标”区域。

1. 编辑需要自动填充的账号。
2. 输入完整登录网址，例如：

   ```text
   https://login.example.com/sign-in
   ```

3. 点击“添加网站”。
4. 确认生成的网站 Origin，例如 `https://login.example.com`。
5. 确保规则处于“启用”状态并保存账号。

匹配采用精确 Origin：

- `https://login.example.com` 与 `http://login.example.com` 不相同。
- `https://example.com` 不会匹配 `https://example.com.evil.test`。
- 跳转到其他域名或子域后，需要为新 Origin 单独配置规则。

## 9. 安装 Chrome/Edge 扩展

### 9.1 找到扩展目录

开发或发布目录中的扩展位置通常为：

```text
release\browser-extension\chrome
release\browser-extension\edge
```

安装版资源中也包含 `resources\browser-extension`。Chrome 与 Edge 可以加载同一份扩展源码，但浏览器显示的扩展 ID 可能不同。

### 9.2 Chrome 加载方法

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 Chrome 扩展目录。
5. 复制扩展卡片显示的32位扩展 ID。

### 9.3 Edge 加载方法

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择 Edge 扩展目录。
5. 复制扩展卡片显示的32位扩展 ID。

### 9.4 在 SafeVault 中登记扩展 ID

1. 启动并解锁 SafeVault。
2. 点击底部“扩展设置”。
3. 填写 Chrome 扩展 ID。
4. 如果 Chrome 和 Edge 显示相同 ID，勾选“Chrome 和 Edge 使用同一个扩展 ID”。
5. 如果 ID 不同，取消勾选并分别填写。
6. 点击“保存并注册”。
7. 等待“扩展配置完成”弹窗并点击“确定”。
8. 返回浏览器扩展页面，重新加载 SafeVault 扩展。

扩展 ID 必须是32位 `a-p` 字符。更换电脑、删除后重新加载扩展或扩展 ID 变化时，重新执行本步骤即可；ID不一致不会损坏密码库，只会导致浏览器暂时无法连接 Native Host。

### 9.5 取消扩展注册

1. 打开“扩展设置”。
2. 点击“取消注册”。
3. 根据提示再次点击“确认取消注册”。

该操作只删除 SafeVault 的 Native Messaging 注册项和清单，不删除加密密码库。

## 10. 使用浏览器自动填充

1. 保持 SafeVault 主程序运行并处于解锁状态。
2. 打开已经配置精确 Origin 的登录页面。
3. 点击浏览器工具栏中的 SafeVault 扩展图标。
4. 从账号摘要列表中选择账号。
5. 扩展填入找到的账号和密码字段。
6. 核对内容后由用户自行点击网站登录按钮。

可能出现的状态：

| 状态 | 处理方法 |
|---|---|
| 主程序未运行 | 启动 SafeVault 后重试 |
| 密码库已锁定 | 回到主程序解锁后重试 |
| 当前网站无匹配账号 | 检查账号的精确网站 Origin 和“启用”状态 |
| 找不到登录字段 | 页面可能使用自绘、封闭 Shadow DOM 或非标准控件，可手工复制 |
| 扩展无法连接 | 检查扩展 ID 登记、Native Host 路径，并重新加载扩展 |

### 10.1 动态表单、iframe 和分步登录

- 扩展会观察动态加入页面的登录字段，但不会持续轮询整个网页。
- iframe 按该 frame 的真实 Origin 独立匹配，跨域 iframe 不继承顶层网页凭据。
- 账号选择上下文最多保留2分钟，并限制在同一标签页、frame 和 Origin 内。
- OTP/一次性验证码字段不会被当作用户名自动填写。

### 10.2 更新网站密码

当用户已经选择过账号，并在支持的密码修改表单中提交新密码时：

1. 扩展显示“是否将新密码保存到 SafeVault”确认框。
2. 确认两次新密码输入一致。
3. 点击确认。
4. 保持 SafeVault 主程序解锁，等待保存提示。

取消确认、账号选择超过2分钟、Origin变化或主程序锁定时，不会更新密码。

## 11. 配置 Windows 程序填充规则

### 11.1 自动识别当前程序

1. 打开目标程序的登录窗口。
2. 在 SafeVault 中编辑对应账号。
3. 点击“识别当前程序”。
4. SafeVault 窗口会暂时隐藏；在约1.5秒内切换到目标登录窗口。
5. SafeVault 恢复后，核对识别出的 `.exe` 路径、窗口标题和字段摘要。
6. 选择填充策略并保存账号。

如果提示字段不唯一，只保存程序身份，不要盲目启用自动填充；可改用剪贴板策略。

### 11.2 手工选择程序

1. 点击“选择程序”。
2. 选择目标程序真实的 `.exe` 文件。
3. 可填写不超过128字符的窗口标题正则作为附加条件。
4. 保存账号。

程序路径是主要身份条件，不能仅靠窗口标题建立规则。

## 12. 使用桌面程序填充

默认全局快捷键：

```text
Ctrl + Shift + L
```

使用步骤：

1. 解锁 SafeVault。
2. 将目标程序登录窗口置于前台。
3. 根据所选策略，把焦点放在账号输入框或保持标准登录表单可见。
4. 按 `Ctrl+Shift+L`。
5. 在弹窗中选择账号。
6. 核对填充结果后自行提交登录。

快捷键被其他程序占用时，SafeVault 会提示快捷键未启用。

### 12.1 UI Automation

默认且推荐的策略。适合暴露标准 Edit/ValuePattern 控件的 Win32、Windows Forms、WPF 和部分 Electron 程序。

- 只在用户名和密码字段唯一时填入。
- 执行前再次检查前台 `.exe` 和窗口标题。
- 不点击“登录”按钮。
- 字段歧义、控件只读、进程切换或权限不足时安全失败。

### 12.2 剪贴板兜底

选择账号后，弹窗允许分别执行“复制账号”或“复制密码”。复制内容默认在30秒后清理，用户需手工粘贴到目标程序。

### 12.3 模拟粘贴兜底

此策略默认不启用，只应对已确认的明确程序规则使用：

1. 将输入焦点放在账号字段。
2. 确认按一次 `Tab` 会移动到密码字段。
3. 按快捷键并选择账号。
4. SafeVault 按固定顺序粘贴账号、发送一次 `Tab`、再粘贴密码。

如果程序字段顺序不符合上述规则，不要使用该策略。

### 12.4 桌面填充明确不支持的场景

- UAC 安全桌面和 Windows 登录界面。
- 权限高于 SafeVault 的管理员程序。
- 远程桌面内部窗口。
- 完全自绘且不暴露标准可访问性控件的界面。
- CAPTCHA、短信验证码、动态令牌、Passkey 或硬件密钥。

## 13. 加密备份、导入与恢复

### 13.1 加密导出

1. 解锁 SafeVault。
2. 点击底部“加密导出”。
3. 选择保存位置。
4. 妥善保存生成的 `safe_vault_encrypted_YYYYMMDD.json`。

该文件仍由主密码保护。建议定期备份到与电脑分离的可信介质。

### 13.2 导入加密备份

1. 点击底部“导入”。
2. 输入备份文件对应的主密码，不一定是当前密码库的主密码。
3. 选择加密备份文件。
4. 查看新增和跳过的账号、网址、记事本数量。

导入采用合并方式，同名账号、相同用户名、同名网址或重复记事本可能被跳过。导入的数据随后使用当前密码库的主密码重新加密保存。

### 13.3 明文导出

“明文导出”会生成直接包含账号、密码和 Token 的 JSON 文件，仅用于受控迁移：

1. 点击“明文导出”。
2. 再次输入当前主密码。
3. 选择安全位置保存。
4. 完成迁移后尽快安全删除不再需要的明文文件。

不要通过聊天软件、普通邮件或公共网盘传输明文导出文件。

### 13.4 忘记主密码

SafeVault 没有主密码找回机制。可行的恢复来源只有：

- 仍记得密码的加密备份；
- 以前妥善保存的明文导出；
- 如果当前会话仍处于解锁状态，可立即逐项复制重要记录，但不能绕过主密码校验重设主密码或执行明文导出。

不要删除无法解锁的密码库，先复制原文件并检查是否有可用备份。

## 14. 卸载与换电脑

### 14.1 卸载

1. 先执行加密导出。
2. 在“扩展设置”中取消注册。
3. 从 Chrome/Edge 删除扩展。
4. 退出托盘中的 SafeVault。
5. 使用 Windows 应用管理或卸载程序卸载。

默认卸载不会删除 `%APPDATA%\safe-vault\safe_vault.json`。如果需要彻底清除数据，应先确认备份，再由用户手工处理该文件。

### 14.2 换电脑

1. 在旧电脑导出加密备份。
2. 在新电脑安装 SafeVault 并创建或解锁密码库。
3. 导入旧电脑的加密备份。
4. 在新电脑重新加载 Chrome/Edge 扩展。
5. 将新电脑显示的扩展 ID重新登记到“扩展设置”。

不同电脑上的扩展 ID可能不同，这是正常现象。

## 15. 常见故障排查

### 15.1 密码库无法打开

- 确认主密码是否正确及键盘大小写状态。
- 检查密码库文件是否被手工修改、同步冲突或安全软件隔离。
- 不要用空白文件覆盖现有密码库。
- 保留原文件和 `.bak` 备份后再尝试恢复。

### 15.2 浏览器扩展提示主程序未运行

- 确认 SafeVault 正在运行，而不仅是浏览器扩展已加载。
- 打开“扩展设置”重新保存 Chrome/Edge ID。
- 在扩展管理页点击“重新加载”。
- 确认 Native Host 清单中的 Bridge 文件仍存在。

### 15.3 当前网站没有账号

- 检查账号是否配置了网站目标并启用。
- 比较协议、域名、子域和端口是否完全一致。
- iframe 登录框可能属于另一个 Origin，需要添加对应规则。

### 15.4 桌面程序无法识别或填充

- 确认目标窗口位于前台。
- 检查程序是否以管理员身份运行。
- 重新执行“识别当前程序”，避免程序升级后路径或窗口标题改变。
- 字段不唯一或自绘时改用剪贴板兜底。
- 模拟粘贴前确认焦点和 `Tab` 顺序。

### 15.5 快捷键没有反应

- 确认密码库已解锁。
- 检查启动时是否提示 `Ctrl+Shift+L` 被其他程序占用。
- 关闭占用该快捷键的程序并重启 SafeVault。

### 15.6 导入失败

- 确认选择的是 SafeVault 加密备份，而不是普通 JSON 或已损坏文件。
- 输入的是备份文件对应的主密码。
- 检查文件读取权限和磁盘空间。

## 16. 安全使用建议

- 使用独立且足够长的主密码，不与网站密码复用。
- 离开电脑时立即锁定 Windows 或 SafeVault。
- 定期制作加密备份并进行恢复验证。
- 不在截图、日志、聊天或问题反馈中附带真实密码。
- 只从可信位置加载扩展和安装包。
- 填充后先核对域名、程序路径和账号，再手工提交。
- 对金融、企业管理和其他高风险账号优先使用 MFA；SafeVault 不代替 MFA。

## 17. 当前验收状态说明

以下核心安全边界已经通过自动验证：加密密码库、锁定拒绝、精确 Origin、Native Host ID 校验、动态字段识别、前台程序路径检查、字段歧义拒绝和剪贴板所有权清理。

截至本手册更新日期，以下内容仍需要在目标环境中进行人工验收：

- Chrome 的完整 Native Messaging 实机流程；
- 20个代表性网站的 Chrome/Edge 实际登录页面；
- Win32、Windows Forms、WPF、Electron、管理员和自绘程序样本；
- 安装版升级、卸载以及与旧版运行实例共存的行为。

人工验收完成前，不应将 SafeVault 描述为可以覆盖全部网站或全部 Windows 程序。
